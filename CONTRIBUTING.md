# Contributing

Contributions and collaborations are welcome.

Please open an issue before changing or adding API, so we can discuss it first.

Before opening a pull request, run both test suites:

- `./gradlew test` runs the unit tests in `src/test`.
- `./gradlew runGameTestServer` runs the game tests in `src/gametest` on a headless server. In the client run, the `/test` command runs them in a world.

Community maintained ports to other mod loaders or Minecraft versions are welcome too, but they will only ever be released as betas.

If you have questions, ask on the [Ametrin Studios discord](https://discord.gg/Ye6WxRV2Tt).
